# Project Tutorial

## Overview
This project features a robot designed and built locally by me. The simulation software used is Unity 2022. Additional vision-related source files are not uploaded to this repository.

## Objectives
The main goal of this project is to enable autonomous navigation between two points. This is achieved using the **Dynamic Window Approach (DWA) algorithm**, which relies on vectors and distance calculations. Additionally, the project integrates the **Gemini API AI** for enhanced functionality and includes real-time image capture from the robot's environment.

## Robot Specifications
The robot consists of the following key components:
1.  A main chassis integrated with four wheels for movement.
2.  A camera for capturing environmental images.
3.  A microphone to receive voice commands for either movement control or AI-assisted support.

## Technical Details
All project files are written in the **C#** programming language.

# برنامج تعليمي للمشروع

## نظرة عامة
يتميز هذا المشروع بروبوت تم تصميمه وبناؤه محليًا بواسطتي. برنامج المحاكاة المستخدم هو **Unity 2022**. ملفات المصدر الإضافية المتعلقة بالرؤية الحاسوبية غير مرفوعة في هذا المستودع.

## الأهداف
الهدف الرئيسي من هذا المشروع هو تمكين التنقل الذاتي بين نقطتين. يتم تحقيق ذلك باستخدام **خوارزمية النافذة الديناميكية (DWA)**، والتي تعتمد على حسابات المتجهات والمسافات. بالإضافة إلى ذلك، يدمج المشروع **واجهة برمجة تطبيقات Gemini للذكاء الاصطناعي** لتحسين الوظائف، ويتضمن التقاط الصور في الوقت الفعلي من بيئة الروبوت.

## مواصفات الروبوت
يتكون الروبوت من المكونات الرئيسية التالية:
1.  هيكل رئيسي مدمج مع أربع عجلات للحركة.
2.  كاميرا لالتقاط صور البيئة المحيطة.
3.  ميكروفون لاستقبال الأوامر الصوتية إما للتحكم في الحركة أو للحصول على الدعم بواسطة الذكاء الاصطناعي.

## التفاصيل التقنية
جميع ملفات المشروع مكتوبة بلغة البرمجة **C#**.
